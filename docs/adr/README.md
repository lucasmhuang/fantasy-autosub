# ADRs

Architecture Decision Records capture durable decisions that are expensive to reverse.

This folder should hold short records for choices like:

- web framework
- database and ORM
- runtime topology
- auth model
- design-system strategy

Suggested naming:

- `0001-use-nextjs-app-router.md`
- `0002-use-postgres-and-drizzle.md`
- `0003-separate-web-and-worker-runtimes.md`
- `0004-custom-magic-link-auth.md`
- `0005-design-system-and-motion-principles.md`

Each ADR should answer:

1. What decision are we making?
2. Why now?
3. What alternatives did we reject?
4. What are the consequences?
